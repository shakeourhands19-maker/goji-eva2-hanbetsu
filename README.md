# スマスロ ゴジラ対エヴァンゲリオン2 設定判別ツール

GitHub Pagesで動作するスマートフォン対応の設定判別・小役カウンターです。

## 公開設定
GitHubリポジトリの **Settings → Pages → Build and deployment → Source** を **GitHub Actions** に設定してください。以後、mainへのpushで自動デプロイされます。

## 機能
- ボーナス・AT初当り確率と通常時スイカ/緑CHANCE経由CZ当選率からの相対推測
- 小役カウンター（設定判別とは別タブ）
- 獲得枚数、終了画面、エンディング中ボイスの記録
- localStorage保存、JSONバックアップ/復元
